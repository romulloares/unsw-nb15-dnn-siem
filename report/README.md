# Relatório final

A entrega final deve usar o template da Sociedade Brasileira de Computação (SBC), ter no máximo 15 páginas e incluir o link deste repositório.

Estrutura recomendada:

1. Descrição do problema;
2. Abordagem;
3. Resultados;
4. Lições aprendidas;
5. Referências.

Quando o template for baixado, coloque os arquivos LaTeX nesta pasta e mantenha figuras finais em `outputs/figures/`.
